# AI 진로·대입 동반자

고등학생의 학년과 학교생활기록부(생기부)를 바탕으로 진로를 분석하고, 대학·학과 추천부터 자기소개 초안 작성까지 하나의 흐름으로 지원하는 AI 서비스입니다.

## 제작 이유

고등학생의 진로 고민은 학년마다 다릅니다. 고1은 다양한 가능성을 발견해야 하고, 고2는 관심 분야와 학교 활동의 연결성을 구체화해야 하며, 고3은 지금까지 쌓은 기록을 대학과 학과의 평가 기준에 맞춰 지원 전략으로 발전시켜야 합니다.

하지만 기존 진로 서비스에는 다음과 같은 한계가 있습니다.

- 학년과 관계없이 비슷한 질문과 결과를 제공합니다.
- 성향이나 성적만으로 대학·학과를 추천해 생기부 활동과 추천 근거의 연결이 부족합니다.
- 진로 적합성과 실제 지원 조건을 하나의 점수로 섞어 보여 줍니다.
- 자기소개를 사실 확인 없이 한 번에 생성해 학생의 실제 경험과 다른 내용이 포함될 수 있습니다.

이 프로그램은 이러한 문제를 해결하기 위해 학년별로 분석 기준과 결과 설명을 달리하고, 모든 추천과 자기소개 문장을 학생의 생기부 원문 또는 추가 답변에 근거하도록 설계되었습니다. 또한 **진로 적합도**와 **지원 참고도**를 분리해 학생이 자신의 관심과 역량뿐 아니라 성적, 지역, 전형 등 현실적인 지원 조건도 함께 판단할 수 있도록 합니다.

## 작동 방식

1. **학년과 분석 목적 선택**
	사용자가 학년과 진로 탐색, 활동 구체화, 지원 준비 등의 목적을 선택하면 학년에 맞는 분석 기준과 가중치를 적용합니다.

2. **기본 정보 입력**
	관심 과목과 활동, 성향, 성취도, 희망 지역·전형 등의 정보를 입력합니다. 고1은 관심과 성향, 고2는 활동의 연결성과 심화 과정, 고3은 생기부와 교과 성취 및 지원 조건을 더 중요하게 반영합니다.

3. **생기부 분석 및 확인**
	업로드한 PDF·이미지·텍스트를 OCR과 문서 파싱으로 처리하고, 개인정보를 마스킹합니다. 이후 교과 세부능력 및 특기사항, 동아리, 진로, 봉사, 독서 등의 기록에서 활동 시기, 주제, 역할, 결과와 배운 점을 추출합니다. 사용자는 원문과 분석 결과를 비교해 잘못된 내용을 수정하거나 제외할 수 있습니다.

4. **학년별 분석 리포트 생성**
	반복해서 나타나는 관심 분야, 역량, 교과·비교과 활동의 연결성과 대표 경험을 분석합니다. 고1에게는 새로운 가능성과 다음 활동을, 고2에게는 관심 분야의 구체화와 보완할 활동을, 고3에게는 지원 서사와 면접 준비 정보를 중심으로 제공합니다.

5. **대학·학과 추천**
	학생의 프로필과 생기부 활동을 공식 대학 데이터와 비교해 대학·학과 후보를 제시합니다. 관심·활동·역량과 학과 교육 내용의 연결 정도인 **진로 적합도**와, 성적·지역·전형 조건을 반영한 **지원 참고도**를 별도로 보여 줍니다. 각 추천에는 생기부의 관련 활동과 확인해야 할 최신 모집 요강 등의 근거가 함께 표시됩니다.

6. **인재상 연결 및 자기소개 초안 작성**
	선택한 대학·학과의 인재상 및 평가 요소를 학생의 실제 경험과 연결합니다. 사용자가 문항과 대표 경험을 선택하고 부족한 정보를 추가로 답하면, 프로그램이 `근거 선택 → 보충 질문 → 개요 → 문단 초안 → 사실 확인` 순서로 자기소개 초안을 만듭니다. 근거가 없는 내용은 생성하지 않고 추가 질문을 요청합니다.

## 학년별 결과

| 학년 | 분석 초점 | 제공 결과 |
| --- | --- | --- |
| 고1 | 관심·성향과 가능성 발견 | 폭넓은 대학·학과 후보, 다음 학기 탐구·동아리·독서 활동, 탐색형 자기소개 |
| 고2 | 활동의 반복성·심화·교과 연결성 | 구체화된 후보, 남은 기간의 활동 계획, 성장 과정 중심 자기소개 |
| 고3 | 학업·진로 역량과 대학 인재상 부합도 | 진로 적합도와 지원 참고도, 예상 면접 질문, 지원동기·1분 소개·면접 답변 초안 |

> 이 프로그램의 추천과 지원 참고도는 대학 합격을 보장하거나 공식 배치표를 대체하지 않습니다. 실제 지원 전에는 반드시 대학의 최신 모집 요강과 전형 조건을 확인해야 합니다.

## 개발 환경 실행

PostgreSQL과 FastAPI를 실행합니다.

```bash
docker compose up -d db
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/alembic -c backend/alembic.ini upgrade head
.venv/bin/python -m uvicorn backend.main:app --reload --port 8000
```

별도 터미널에서 Next.js를 실행합니다.

```bash
cd frontend
npm install
npm run dev
```

환경변수는 [API 키 관리 가이드](docs/API_KEY_MANAGEMENT.md), 회원과 학생 프로필 구조는 [인증 및 프로필 문서](docs/AUTH_AND_PROFILE.md)를 참고하세요.
