# good 초등학생 행사 체험 모드 설계

## 문서 목적

이 문서는 `good` 서비스 안에 파인콘 행사 전용 초등학생 체험 모드를 추가하기 위한 설계를 정의한다. 목표는 로그인 없이 빠르게 체험할 수 있는 독립 흐름을 제공하고, 초등학생의 관심사와 성향을 바탕으로 AI가 진로·직업을 추천하며, 결과를 현장에서 PDF로 출력할 수 있게 만드는 것이다.

이 기능은 현재 `good`의 고등학생용 로그인·프로필·설문·생기부·리포트 흐름과 명확히 분리된 경험이어야 하며, 홈 화면에서 별도 진입점으로 들어가는 구조를 사용한다.

## 현재 코드베이스 전제

`good`은 다음 구조를 가진다.

- 프론트엔드: Next.js App Router
- 백엔드: FastAPI
- 인증: 세션 쿠키 기반 로그인
- 기존 핵심 라우트:
  - `/login`
  - `/signup`
  - `/profile`
  - `/survey`
  - `/records`
- 기존 백엔드 라우터:
  - `backend/routers/auth.py`
  - `backend/routers/profiles.py`
  - `backend/routers/records.py`
  - `backend/routers/reports.py`

초등학생 행사 체험은 이 기존 구조를 깨지 않고, 별도 `kids-experience` 경로와 라우트 집합으로 추가한다.

## 배경과 문제

현재 `good`은 고등학생의 진로·대입 분석을 목표로 설계되어 있다. 회원가입, 학생 프로필 입력, 설문 응답, 학교생활기록부 분석, 진학 리포트 생성 흐름은 행사 현장에서 초등학생이 5분 안에 체험하기에는 무겁다.

파인콘 행사에서는 다음 요구가 새롭게 생긴다.

- 로그인 없이 바로 시작할 수 있어야 한다.
- 실제 개인정보나 생기부 없이도 체험할 수 있어야 한다.
- 대부분의 입력은 선택형이어야 한다.
- 결과는 대학·전공보다 직업·흥미 중심이어야 한다.
- 결과를 PDF로 즉시 저장하거나 출력할 수 있어야 한다.
- 현장 네트워크 또는 AI 호출이 불안정해도 fallback 결과를 제공해야 한다.

즉, `good` 안에 별도의 행사 체험 전용 미니 서비스가 필요한 상태다.

## 목표

- 기존 홈 화면에서 `초등 진로 체험` 전용 진입점을 제공한다.
- 로그인 없이 시작하는 별도 라우트 기반 체험 모드를 제공한다.
- 입력은 이름, 좋아하는 주제, 좋아하는 활동 방식, 성향 검사 8문항, 한 줄 자유입력, 그리고 결과 품질을 높이는 보조 선택형 입력으로 구성한다.
- 결과는 성향 요약, 강점 키워드, 직업/진로 추천 3개, 추천 이유, 보호자/학교 관찰 포인트, 숨은 가능성 분야, 후속 활동을 포함한다.
- 결과 화면에서 버튼형 AI 상담 3개를 제공한다.
- 결과를 2장 내외 PDF 리포트로 생성하고 다운로드/출력할 수 있게 한다.

## 비목표

- 행사 체험에서 로그인, 회원가입, 학생 프로필 저장을 요구하지 않는다.
- 생기부 업로드, 내신, 모의고사, 대학/전형 추천은 포함하지 않는다.
- 자유 채팅형 장문 상담 UI는 포함하지 않는다.
- 기존 고등학생용 `/api/analysis`, `/api/reports`, `/api/records` 흐름에 체험 기능을 섞지 않는다.
- 행사 첫 버전에서는 체험 결과의 장기 저장, 관리자 대시보드, 보호자 계정까지 포함하지 않는다.

## 추천 접근 방식과 선택 이유

### 접근 1. `good` 내부 완전 분리형 행사 모드

- 홈에 전용 카드 추가
- `/kids` 이하 전용 프론트 페이지 추가
- `/api/kids-experience/*` 전용 백엔드 API 추가

장점:

- 기존 고등학생용 코드와 충돌이 적다.
- 행사 전용 UI·문구를 자유롭게 조정할 수 있다.
- 배포 후에도 온오프가 쉽다.

단점:

- 별도 프론트/백엔드/PDF 로직을 추가 구현해야 한다.

### 접근 2. 기존 `/survey` 및 `/reports` 흐름 재활용

장점:

- 일부 화면과 분석 흐름을 재활용할 수 있다.

단점:

- 로그인과 고등학생 데이터 모델에 종속된다.
- 행사 UX를 가볍게 만들기 어렵다.
- 성향/직업 중심 결과를 대입 중심 결과와 분리하기 어렵다.

### 최종 선택

접근 1을 채택한다. `good` 안에 별도 전용 흐름을 추가하고, 기존 고등학생용 기능과는 API 레벨에서도 분리한다.

## 사용자 경험 개요

### 진입

기존 홈 화면에 `초등 진로 체험` 또는 `길잡이 키즈 체험` 카드/배너를 추가한다. 이 진입점은 고등학생용 로그인/회원가입 CTA와 시각적으로 구분되어야 한다.

### 체험 흐름

1. 시작 화면
2. 관심사/활동 방식/보조 입력 선택
3. 성향 검사 8문항
4. 결과 생성
5. 결과 화면
6. PDF 저장 또는 출력

전체 체험 시간 목표는 3~5분이다.

## 정보 구조와 라우팅

추천 라우트 구조는 다음과 같다.

- `/`
  - 기존 홈
  - `초등 진로 체험` 진입 카드 추가
- `/kids`
  - 시작 화면
  - 이름 또는 별명 입력
  - 체험 소개
- `/kids/questions`
  - 1단계: 관심 주제, 활동 방식, 보조 입력
  - 2단계: 성향 검사 8문항
- `/kids/result`
  - 성향 타입
  - 강점
  - 직업 추천 3~5개
  - 추천 이유
  - 버튼형 AI 상담
- `/kids/report`
  - PDF 미리보기 또는 다운로드/출력

## 입력 설계

### 1. 기본 정보

입력 필드:

- 이름 또는 별명

요구사항:

- 필수 입력으로 받되, `이름 또는 별명`으로 안내한다.
- 결과 화면과 PDF에 이름을 사용한다.

### 2. 좋아하는 주제 선택

입력 방식:

- 다중 선택
- 권장 선택 수: 3~5개

초기 후보 예시:

- 동물
- 우주
- 공룡
- 로봇
- 발명
- 그림
- 음악
- 운동
- 요리
- 자연
- 게임/컴퓨터
- 사람 돕기
- 이야기 만들기
- 실험하기

### 3. 좋아하는 활동 방식 선택

입력 방식:

- 다중 선택
- 권장 선택 수: 2~4개

초기 후보 예시:

- 만들기
- 관찰하기
- 발표하기
- 친구와 함께하기
- 문제 풀기
- 상상하기
- 몸으로 움직이기
- 꾸미기
- 설명하기
- 도와주기

### 4. 한 줄 자유 입력

질문:

- `요즘 제일 좋아하는 것은 뭐야?`

예시 placeholder:

- `축구하기`
- `강아지 영상 보기`
- `레고 만들기`

요구사항:

- 결과의 개인화 체감을 높이기 위해 포함한다.
- 입력이 비어 있어도 진행은 가능하게 한다.

### 5. 균형 확장 보조 입력

기존 흐름을 무겁게 만들지 않으면서 AI가 더 사람다운 상담 문장을 생성할 수 있도록, 선택형 보조 입력 4개를 추가한다. 이 입력들은 모두 빠르게 답할 수 있어야 하며, 긴 서술형을 요구하지 않는다.

#### 5-1. 요즘 자주 하는 활동

- 질문: `요즘 자주 하는 건 뭐야?`
- 형식: 단일 선택 또는 최대 2개 선택
- 예시:
  - 레고 만들기
  - 그림 그리기
  - 책 읽기
  - 운동하기
  - 블록 놀이
  - 동생 챙기기
  - 만들기 놀이

목적:

- “좋아하는 것”과 “실제로 자주 하는 것”을 분리해서 본다.
- AI가 흥미뿐 아니라 생활 속 습관과 몰입 장면을 설명할 수 있게 한다.

#### 5-2. 더 편한 활동 분위기

- 질문: `어떨 때 더 편해?`
- 형식: 단일 선택
- 선택지:
  - 혼자 천천히
  - 친구와 함께
  - 둘 다 좋아

목적:

- 협업형/몰입형 성향을 추천 직업 설명과 관찰 포인트에 반영한다.

#### 5-3. 만들고 싶은 결과물

- 질문: `무엇을 만들거나 보여주는 게 좋아?`
- 형식: 최대 2개 선택
- 선택지 예시:
  - 작품 만들기
  - 이야기 들려주기
  - 발표하기
  - 문제 해결하기
  - 사람 돕기
  - 꾸미기
  - 관찰 기록 남기기

목적:

- 추천 직업의 이유를 행동 중심으로 설명할 수 있게 한다.
- “다음에 해보면 좋은 활동”의 품질을 높인다.

#### 5-4. 최근 뿌듯했던 순간

- 질문: `최근에 스스로 뿌듯했던 순간은 언제야?`
- 형식: 선택형
- 선택지 예시:
  - 내가 만든 걸 보여줬을 때
  - 친구를 도와줬을 때
  - 어려운 걸 해냈을 때
  - 새로운 걸 해봤을 때
  - 오래 집중했을 때

목적:

- 강점 문장을 추상적인 형용사 대신 실제 장면 기반으로 쓰게 한다.
- 보호자 메시지와 격려 문장을 더 상담형으로 만든다.

### 6. 성향 검사 8문항

형식:

- 정확히 8문항
- 각 문항은 2지선다 또는 3지선다
- 질문 문장은 짧고 쉬워야 한다.

문항 방향 예시:

1. 혼자 차분히 하는 게 좋아 / 친구와 함께하는 게 좋아
2. 바로 해보는 게 좋아 / 먼저 잘 살펴보는 게 좋아
3. 직접 만드는 게 좋아 / 말로 설명하는 게 좋아
4. 상상하는 게 좋아 / 자세히 관찰하는 게 좋아
5. 계획을 세우는 게 좋아 / 떠오르는 대로 해보는 게 좋아
6. 문제를 푸는 게 좋아 / 사람을 돕는 게 좋아
7. 새로운 것을 도전하는 게 좋아 / 익숙한 것을 깊게 하는 게 좋아
8. 꼼꼼하게 하는 게 좋아 / 신나게 빠르게 하는 게 좋아

요구사항:

- 큰 버튼형 선택지를 사용한다.
- 진행률을 표시한다.
- 질문 수는 8개지만 체감은 가볍게 느껴져야 한다.

## 성향 유형 설계

MBTI 코드 대신 초등학생 친화적 이름을 사용한다. 성향 유형은 6~8개 범위로 제한한다.

초기 유형 예시:

- 호기심 탐험가
- 다정한 협력가
- 상상력 발명가
- 꼼꼼한 관찰자
- 씩씩한 도전자
- 이야기 창작자
- 문제 해결사
- 감성 예술가

각 유형은 다음을 포함한다.

- 이름
- 1~2문장 설명
- 대표 강점 키워드
- 어울리는 직업군 연결 힌트

## 결과 화면 설계

결과 화면은 카드형 중심으로 구성한다.

### 1. 상단 요약

- `OOO에게 어울리는 미래 직업을 찾아봤어!`
- 성향 요약 한 줄

### 2. 나의 성향 타입

- 성향 이름
- 짧은 설명

### 3. 추천 직업/진로 3개

각 카드에는 다음이 포함된다.

- 직업 이름
- 짧은 추천 이유
- 연결된 관심사 태그 2~3개
- 학교에서 이렇게 해봐요
- 집에서는 이렇게 놀아봐요
- 이런 친구에게 잘 어울려요

### 4. 나의 강점 키워드

예시:

- 호기심
- 상상력
- 협동심
- 끈기
- 관찰력

### 5. 다음에 해보면 좋은 활동

예시:

- 동물 도감 만들기
- 작은 발명품 만들기
- 좋아하는 주제로 발표해 보기
- 자연 관찰 기록장 쓰기

### 6. 버튼형 AI 상담

버튼형 3개를 제공한다.

예시:

- 왜 이 직업이 어울려?
- 내가 잘하는 점은 뭐야?
- 비슷한 다른 직업도 알려줘

버튼을 누르면 아래에 짧은 AI 답변이 펼쳐지는 방식으로 구현한다.

### 7. 보호자/학교용 상담 메모

결과 하단에는 아래 항목을 별도 카드로 보여준다.

- 집에서 이렇게 지켜봐 주세요
- 학교에서 이렇게 응원해 주세요
- 부모님께 먼저 전하는 말
- 다음에 이렇게 물어봐 주세요

### 8. 숨은 가능성 분야

직업과 별도로 2~4개의 확장 가능성 분야를 노출한다.

예시:

- 생명 관찰
- 창의 발명
- 과학 스토리텔링
- 협력 리더십

목적:

- 직업명을 넘어 넓은 가능성을 보여준다.
- 보호자가 결과를 “하나의 정답”으로 받아들이지 않게 돕는다.

## 백엔드 설계

행사 모드는 기존 인증 기반 라우터와 분리된 공개 API로 구현한다.

추천 API:

- `POST /api/kids-experience/analyze`
  - 입력:
    - participantName
    - favoriteTopics
    - favoriteActivities
    - freeTextNote
    - personalityAnswers
  - 출력:
    - personalityType
    - personalitySummary
    - strengthKeywords
    - recommendedJobs
    - suggestedActivities
    - quickCounsel
    - reportSections
    - fallbackUsed

- `POST /api/kids-experience/report`
  - 입력:
    - analyze 응답 payload
  - 출력:
    - PDF 파일

요구사항:

- 로그인 의존이 없어야 한다.
- 입력 검증은 FastAPI schema 수준에서 수행한다.
- AI 호출이 실패하면 fallback 결과를 반환할 수 있어야 한다.
- 초기 버전은 DB 저장 없이 stateless하게 동작해도 된다.

## AI 결과 생성 전략

초기 구현은 두 단계로 간다.

1. 행사 안정성을 위한 fallback 규칙 기반 결과
2. APIM 연결 시 AI가 구조화된 JSON 결과 생성

즉, 행사 현장에서는 AI가 연결되지 않아도 최소한의 추천 경험은 유지돼야 한다.

AI 출력 구조는 자유문장만 반환하지 않고 구조화된 JSON 형태를 따라야 한다.

추천 출력 필드:

- participantName
- personalityType
- personalitySummary
- strengthKeywords
- recommendedJobs
  - title
  - reason
  - fitComment
  - tags
  - schoolHint
  - homeMission
  - friendFit
- suggestedActivities
- quickCounsel
  - whyThisFits
  - strengths
  - alternativeJobs
- reportSections
  - oneLineSummary
  - profileOverview
  - strengthsSummary
  - homeObservationPoints
  - schoolSupportPoints
  - parentMessage
  - nextTalkQuestion
  - hiddenPotentialFields
  - closingMessage

규칙:

- 추천 직업 수는 정확히 3개
- 결과는 초등학생이 이해할 수 있는 쉬운 한국어 문장
- 부정적 표현보다 가능성 중심 표현
- 단정이 아니라 탐색형 제안으로 마무리

### 문장 품질 원칙

- 판정형 문장을 피한다.
- “이 아이는 ~할 때 반짝이는 편”처럼 관찰형 문장을 사용한다.
- 입력값과 연결된 근거를 문장 안에 드러낸다.
- 보호자가 바로 이해할 수 있는 쉬운 단어를 사용한다.
- 결과를 정답처럼 보이게 하지 않는다.

## PDF 리포트 설계

PDF는 2장 내외 상담 리포트형으로 구성한다.

### 1페이지

- 제목: `OOO의 미래 직업 탐험 리포트`
- 성향 타입
- 성향 설명
- 오늘의 상담 한 줄 총평
- 상담 선생님이 본 전체 모습
- 강점 키워드
- 첫 번째 추천 활동

### 2페이지

- 추천 직업 3개 카드
- 직업별 추천 이유
- 학교/집 활동 제안

### 3페이지

- 다음에 해보면 좋은 활동
- 집에서 이렇게 지켜봐 주세요
- 학교에서 이렇게 응원해 주세요
- 숨은 가능성 분야
- 아이에게 전하는 한마디

### 4페이지

- 부모님께 먼저 전하는 말
- 다음에 이렇게 물어봐 주세요
- 오늘 결과 활용 팁
- 안내 문구:
  - `이 결과는 정답이 아니라, 나에게 어울리는 가능성을 찾아보는 탐험 지도예요.`

요구사항:

- 행사 현장 출력용으로 여백과 가독성을 충분히 확보한다.
- 보호자나 운영 학생이 함께 봐도 이해 가능한 문장으로 구성한다.

## 에러 처리

행사 운영 특성상 실패 시 사용자가 멈추지 않는 것이 중요하다.

에러 처리 원칙:

- 분석 실패 시 fallback 결과를 보여준다.
- PDF 생성 실패 시 `다시 생성하기`를 제공한다.
- 입력 단계는 로컬 상태 중심으로 관리해 네트워크 의존을 최소화한다.
- 결과 대기 중에는 친근한 로딩 메시지를 보여준다.

## 테스트 전략

### 프론트엔드

- 홈 진입 카드 렌더링
- 이름 입력과 시작 버튼
- 관심 주제/활동 방식 선택 제한
- 성향 검사 8문항 진행률
- 결과 카드 렌더링
- 버튼형 AI 상담 상호작용
- PDF 다운로드 버튼

### 백엔드

- analyze 요청 검증
- analyze 응답 contract
- fallback 결과 생성
- report PDF 응답

## 보안과 개인정보 원칙

- 로그인 없이 사용한다.
- 이름/별명 외 민감정보는 받지 않는다.
- 생기부, 학교명, 연락처, 생년월일은 받지 않는다.
- 장기 저장이 없어야 하며, 필요 시에도 행사 범위 안에서 최소화한다.

## 성공 기준

- 초등학생이 5분 이내에 체험을 완료할 수 있다.
- 로그인 없이 홈에서 바로 체험을 시작할 수 있다.
- 선택형 입력만으로도 3~5개의 직업 추천이 안정적으로 생성된다.
- 버튼형 AI 상담 3개가 기대대로 동작한다.
- 결과를 2장 내외 PDF로 출력할 수 있다.
- 기존 고등학생용 `good` 기능을 깨지 않는다.
