# Kids Report Polish Design

## Goal

초등 진로 체험 결과 화면을 더 완성도 높은 상담 리포트처럼 보이게 다듬고, PDF 미리보기와 저장 경험을 결과 화면 흐름과 자연스럽게 연결한다.

## Scope

- 결과 화면 상단을 표지형 히어로로 재구성한다.
- PDF 미리보기를 인라인 영역이 아닌 모달형 레이어로 전환한다.
- 백엔드 PDF 생성 순서와 제목을 결과 화면 정보 구조에 더 가깝게 맞춘다.

## Design

### 1. 결과 상단 표지

현재 상단은 정보가 많지만 위계가 약하다. 이를 표지형 레이아웃으로 바꿔서 한눈에 “상담 리포트 첫 장”처럼 느껴지게 만든다.

- 좌측: 리포트명, 참여자 이름, 성향 타입, 상담 한 줄 총평
- 우측: 핵심 요약 카드
  - 대표 추천 방향
  - 가장 잘 보이는 강점
  - 다음에 해보면 좋은 활동
  - 핵심 키워드
- 하단: “이 리포트는 지금 좋아하는 것에서 미래의 힌트를 찾는 첫 상담 기록” 같은 안내 문구 유지

### 2. PDF 미리보기 UX

현재는 결과 화면 아래에 iframe이 열리는데, 리포트 확인 경험이 분산된다. 이를 전면 모달로 바꾼다.

- 배경 딤 처리
- 큰 모달 카드 안에 PDF iframe 배치
- 상단에 제목과 설명
- 우측 상단 닫기 버튼
- 하단 또는 상단 액션 영역에 저장 버튼

이렇게 하면 결과 화면을 읽다가 “출력 전 미리 확인” 흐름이 더 자연스럽다.

### 3. PDF 구조 정렬

PDF는 화면과 완전히 똑같은 HTML 캡처 방식이 아니라, 현재 안정적인 백엔드 생성 방식을 유지하되 섹션 순서와 카피를 화면 구조에 맞춘다.

권장 순서:

1. 표지 / 한눈에 보기
2. 추천 직업
3. 다음 활동
4. 상담 노트
5. 숨은 가능성 / 관찰 포인트 / 응원 포인트
6. 보호자 가이드 / 다음 대화 질문 / 마무리

이렇게 하면 웹 화면과 PDF가 같은 리포트의 두 표현처럼 연결된다.

## Constraints

- 기존 결과 데이터 스키마는 유지한다.
- PDF는 기존 `/api/kids-experience/report` 응답 방식을 유지한다.
- 프론트에서 PDF를 직접 그리지 않고, 백엔드 PDF를 미리보기/저장한다.
- 기존 테스트 패턴을 유지하며 UI 변경에 맞는 테스트를 추가한다.
